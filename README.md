# TanStack Starter Template

This is my personal use for tanstack starter template boilerplate, including these packages

- **Bun**
- **TanStack Start**, and other tanstack libraries
- **Shadcn**, with dark mode, blocks and template boilerplate
- **Oxc (oxlint + oxfmt)**, with predefined vscode settings, agent hook and CI
- **React Doctor**, with predefined agent hook and CI
- **GitHub Actions**
- **GitLab CI**
- **Dockerfile**
- **Skills**
- **Fumadocs** (wip)
- **Reactbits** (wip)

## Getting Started

Clone this project, it will clone all template

```
git clone git@github.com:imbagila/tanstack-shadcn-starter.git
```

Install dependencies

```
bun install
```

Run the application

```
bun run dev
```

## Clone Specific Template

This is example to clone base shadcn, auth block, tanstack authed route, tanstack start, tanstack form, tanstack query

```
git clone --branch base-auth --single-branch git@github.com:imbagila/tanstack-shadcn-starter.git
```

It will only get `base-auth` source code template.

If you want to also get all of the source code but want to start work from `base-auth`, run this command

```
git clone --branch base-auth git@github.com:imbagila/tanstack-shadcn-starter.git
```
